# 14 אפקטי הריל (HyperFrames, פרויקט `video/my-reel`)

ריל אנכי 1080×1920 בשפה עיצובית אחת: הסרטון המקורי, שכבת "מאחור", הקאט-אאוט של הדובר מסונכרן פריים מול פריים,
שכבת "מלפנים" וכותרות, הכל על טיימליין GSAP אחד מושהה ודטרמיניסטי. החוק הוא `video/my-reel/style.md`, הקטלוג הוא
`video/my-reel/effects/catalog.json`, המימוש הוא `effects/fx.js` ו-`effects/fx.css`, והבנייה היא `build.mjs`.

## מאיפה מגיעה הבקשה

1. **מהמנוע.** במסמך הווידאו (`videos`) יש שדה `reel` (תוכנית בפורמט `plan.json`) ו-`reelPrompt` (הפרומפטים בעברית, שורה לכל אפקט).
   הבעלים בחר אותם בעורך: חבילה לפני העריכה, אפקט על מילה, או אפקט בפריים שבו עצר על סרטון מוכן (`at` בשניות).
2. **מפרומפט.** המשתמש מדביק שורות "על המילה [מילה]: ..." מהקטלוג. ממפים כל שורה ל-`id` בקטלוג ובונים `plan.json`.

אפקט בלי `word` ובלי `at` מציבים על המילה החזקה הבאה בתמלול לפי הסדר, ומדווחים בתוכנית איזו מילה נבחרה.

## התהליך

```bash
cd video/my-reel
cp <source.mp4> assets/video.mp4                                   # המקור (אחרי חיתוך, 9:16, צבע)
npx hyperframes@0.8.193 remove-background assets/video.mp4 -o assets/cutout.webm --quality best
# תמלול עם זמן לכל מילה -> transcript.json ({words:[{word,start,end}]}). בענן של Claude Code whisper חסום:
#   python3 ../engine/transcribe.py assets/video.mp4 --out transcript.json   (Deepgram, Groq או OpenAI)
#   או קובץ מילים מהמחשב של המשתמש: npx hyperframes transcribe assets/video.mp4 --model large-v3 --language he
# לעולם לא ממציאים תמלול. בלי תמלול עובדים רק עם at (שניות).
node build.mjs plan.json            # -> index.html: 5 שכבות, טיימליין אחד, כותרת NN/14 לכל אפקט
npx hyperframes@0.8.193 check --json
npx hyperframes@0.8.193 snapshot --at <תחילת כל אפקט + 0.5>
npx hyperframes@0.8.193 render --quality delivery --output out.mp4
```

`plan.json`:
```json
{ "source": "assets/video.mp4", "cutout": "assets/cutout.webm", "duration": 14.7, "fps": 30, "accent": "#FF7A3D",
  "titles": true, "debug": false,
  "effects": [ { "id": "pill", "word": "בית", "params": { "text": "בית" } },
               { "id": "pin", "at": 9.3, "params": { "text": "הוד השרון" } } ] }
```
- `titles:false` מכבה את הכותרות `NN/14` (לגרסה הסופית). `debug:true` מעמעם את המקור ומצייר פס מאחורי הדובר כדי להוכיח
  שהקאט-אאוט מסונכרן (שלב 4 עד 6 של ההקמה).
- `build.mjs` מקצר אפקט שחופף לבא אחריו, ומזהיר על אפקט שרץ אחרי סוף הסרטון או קצר מכניסה ויציאה.
- מגבלות מהשפה: כל אפקט עד 1.5 שניות, כניסה 0.35 (`power3.out`), יציאה 0.25 (`power2.in`), אזור פנים 22% עד 48% מהגובה
  נשאר נקי, אזור בטוח 72px מהצדדים, 180px מלמעלה, 260px מלמטה.

## מה בודקים לפני שמראים

- `check` ירוק בכל השערים (lint, runtime, layout, motion, contrast, craft). אזהרת `line_unread` על כותרת `NN/14` מותרת
  כשהאפקט קצר במכוון; `text_occluded` על אפקט "מאחור" פירושו שהקאט-אאוט מכסה אותו לגמרי, מזיזים את ה-`top`.
- פריים מכל אפקט: נוחת על המילה שלו, לא מכסה עיניים ופה, הטקסט קריא.
- הקאט-אאוט והמקור באותו `data-start` ו-`data-media-start` (ה-build שומר על זה).

## אפקט חדש

מוסיפים ערך ב-`effects/catalog.json`, פונקציה `FX.<id>` ב-`effects/fx.js` (DOM בזמן בנייה, tweens על הטיימליין המשותף,
בלי CSS animation, בלי `Math.random` חופשי, `fx.rng(seed)` אם צריך פיזור), עיצוב ב-`fx.css` לפי `style.md`, ואת אותו ערך
ב-`docs/agents/video-editor/v221.js` (`CAT`) כדי שיופיע בעורך. בודקים עם `plan.demo.json`.
