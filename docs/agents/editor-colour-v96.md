# עורך הפוסטים: צבע לכל אלמנט (v96)

## מה נוסף
- בלשונית "שכבות" אפשר לבחור כל אלמנט (טקסט, כותרת בקופסה, תגית, מדבקה, כפתור, סקר, שלבים, צורות דקורטיביות ועוד) ולהחליף לו צבע.
- שורת הצבע מציגה קודם את צבעי המותג של קורקוס: כחול קורקוס, אדום קורקוס, טורקיז, תכלת, תכלת חיוורת, נייר, לבן, דיו, אפור כחלחל.
- אחרי צבעי המותג יש בוחר צבע חופשי (כל צבע), וכפתור "מקורי" שמחזיר את צבע התבנית.
- ביטול (Ctrl+Z או סרגל הביטול) מחזיר את הצבע הקודם.

## איך זה עובד
- אלמנטים חד-צבעיים (טקסט, קו, מלבן, מסגרת, חץ, רשימה, מונה) מקבלים את הצבע שנבחר כמו שהוא.
- אלמנטים מרובי צבעים (כותרת בקופסה, תגית, מדבקה, כפתור, סקר, שלבים, ציר זמן, צורות) מקבלים את הצבע על החלקים הכהים, והחלקים הבהירים (טקסט לבן בתוך קופסה) נשארים קריאים. אם נבחר צבע בהיר, הטקסט הבהיר הופך לכחול קורקוס.
- הבחירה נשמרת על הפוסט (`fx.tf[key].col` לאלמנטים, `fx.decoTf[id].col` לצורות) ולא משנה את התבנית עצמה.

## תיקון נלווה
- צורות דקורטיביות לא נרשמו כשכבות ניתנות לבחירה בגלל חיפוש ברשימה הלא נכונה (`DECO.list`). תוקן, וכעת כל צורה מופיעה ברשימת השכבות עם שורת צבע.

## בדיקות
- `v96t.cjs`: בחירת כותרת בקופסה, אדום קורקוס מצבע את הקופסה, צבע חופשי מחליף, הטקסט הלבן נשאר.
- `v96d.cjs`: צורה דקורטיבית מופיעה כשכבה ומקבלת צבע טורקיז.
- רגרסיה: touchdrag, lt, closet, qatest, pk, cmp, v95t עברו ללא שגיאות.
