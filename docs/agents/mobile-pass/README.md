# מעבר מובייל (v99): גלילה, כניסה ויציאה מכל עמוד, לוגו אחד, עורך בכל מקום

## מה נמצא ותוקן
1. **לוגו.** 16 פוסטים בפריסות הישנות (tape, ab, pano, weave, mask, stamp, bignum, wipe, carousel, numbers, tips, split)
   לא קיבלו את הלוגו המלא ובמקומו צויר סימן הפסים לבד (הלוגו "החתוך"), כי שכבת הלוגו דילגה על פוסטים בלי `fx`.
   תוקן: כל פוסט מקבל לוגו מלא אחד. סימן הפסים בוטל בכל המסלולים: בשכבת הלוגו (מצב "סימן בלבד" הוסר מהעורך
   ומתפרש כלוגו מלא), במסגרת המערכת של התבניות, ובסימן המים של הסטודיו. ביקורת מרונדרת (`logoaudit.cjs`) סופרת
   ציורי לוגו לכל פוסט: 741 פוסטים, לכולם בדיוק לוגו אחד, אפס פסים.
2. **כותרת העמוד במובייל.** בעמודים עם פעולות (גלריה, תבניות, לוח שנה, מתחרים, סטודיו, שיבוט, הגדרות) שורת הכותרת
   נשברה לשתיים ושלוש שורות וכפתור "פוסט חדש" ירד למטה. עכשיו: שורה אחת קבועה (תפריט, כותרת, חיפוש, התראות, חדש),
   ושורת הפעולות של העמוד נגללת לרוחב בלי לעטוף.
3. **העורך בכל מקום.** כל תמונת פוסט במערכת היא כניסה לעורך: נגיעה בתמונה (פיד, ניתוח, רעיונות, היום, תור) פותחת
   את העורך, וכפתור עיפרון קטן יושב על כל תמונה שאין לה פותח משלה. בגלריה הנגיעה פותחת את חלון התצוגה שלה
   (עם כפתורי עריכה), בלוח השנה ובתור הכרטיסים פותחים את הקומפוזר ("ערוך עיצוב" בתוכו).
4. **ניווט תחתון בטלפון.** חמישה כפתורים קבועים בתחתית המסך: היום, תור, לוח, גלריה, תפריט (פותח את המגירה).
   המגירה נסגרת בנגיעה מחוץ לה ובבחירת עמוד. הסרגל מוסתר כשהעורך, הקומפוזר או המגירה פתוחים.
5. **קטנות.** ההודעות הקופצות עלו מעל הסרגל, הערות המשפחה הארוכות בעמוד התבניות מקופלות לשלוש שורות עם "עוד".

## מה אומת (טלפון 390x844, מגע אמיתי)
`navtest.cjs`: כניסה לכל 17 העמודים דרך המגירה ויציאה מהם, בלי שגיאות JS, בלי גלילה אופקית, הגלילה מגיעה לסוף
בכל עמוד, גובה הכותרת 64 (או 101 עד 105 עם שורת פעולות). ניווט תחתון לארבעת העמודים. עורך נפתח ונסגר מפיד,
ניתוח, רעיונות, היום ותור. לוח שנה ותור פותחים קומפוזר עם כפתור עיצוב. גלריה פותחת חלון תצוגה עם כפתור עריכה.
קומפוזר נפתח ונסגר. רגרסיה: שכבות, צביטה, סגירה בנגיעה אחת, QA.
