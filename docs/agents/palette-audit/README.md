# ביקורת פאלטה: כל הפוסטים בצבעי קורקוס (v98)

## מה נמצא
1. קובץ התבניות שפורסם (`new_templates.json`) חזר לצבעי המותגים המתחרים (סגול של מאנדיי, זהב של ישראל קנדה,
   ירוק של שיכון ובינוי ועוד, 115 צבעים מחוץ לפאלטה ב350 תבניות). הסיבה: הבנייה מחדש של הקובץ בסבב 3 דילגה על שלב
   הצביעה מחדש (`recolor.py`). תוקן, ושלב הצביעה מחדש נכנס עכשיו לתוך `final_build.py` כך שכל תבנית שיוצאת ממנו
   היא בפאלטה, לא משנה באיזו פאלטה נכתבה.
2. במנוע עצמו היו צבעים שאינם בפאלטה: זהב (#ffd47a) בערכת "לילה וזהב" וברשימות הפלוס, ירוקים בגרדיאנט, אפורים
   כחלחלים (#8898aa, #4f5866, #58606e, #cbd2db ועוד), קרמים בלוח הכתיבה (חום) ובפסי ההדגשה, ותכלת חיוורת בלוגו
   הלבן. כולם הוחלפו בצבע הקרוב מהפאלטה: זהב לתכלת, ירוקים לטורקיז וכחול, אפורים לאפור כחלחל (#5b6472),
   קווים ורקעים עדינים לתכלת חיוורת (#dbe8ee). הערכה "לילה וזהב" נקראת עכשיו "לילה ותכלת".

## הפאלטה
כחול קורקוס #07293a, אדום קורקוס #a90b0c, טורקיז #105572, תכלת #8fb6c8, תכלת חיוורת #dbe8ee, נייר #f4f6f8 / #f7f8fa,
לבן #ffffff, דיו #0b1f2a, אפור כחלחל #5b6472 / #35505e. שקיפויות ודהיות של הצבעים האלה מותרות.

## איך אומתו
- סטטי: אין אף hex מחוץ לפאלטה ב`new_templates.json` (830 תבניות) ובקוד הציור של המנוע.
- מרונדר: `palaudit.cjs` מרנדר כל פוסט וכל תבנית, מחליף את הצילומים במלבן תכלת, ובודק כל פיקסל "שטוח" (לא צילום)
  מול הפאלטה ומול מיזוגים שלה (צבע פאלטה מעל לבן, כחול או שחור). תוצאה: 655 פוסטים, 0 חריגים. 1700 תבניות,
  12 חריגים, כולם וריאציות "אדום" של משפחת "מה שעובד למתחרים" שבהן דהייה אדומה חזקה מעל הצילום הופכת את השמיים
  לסגלגל. זו טיפול בצילום באדום קורקוס, לא צבע זר, ולכן הושאר.
