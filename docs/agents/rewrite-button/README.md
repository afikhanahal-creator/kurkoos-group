# כפתור "כתוב מחדש הכל"

בעורך הפוסט, לשונית טקסט, ובחלון הפוסט. לחיצה אחת כותבת מחדש את הכותרת, שורת המשנה, התווית, הכפתור והכיתובים לפייסבוק ולאינסטגרם.

- מאחורי הכפתור: הנחיה שמבוססת על בריף הכתיבה (`docs/agents/copy-rewrite/brief.md`), עם קול המותג, העובדות המותרות, כללי ההוק והמנגנונים לסיום, והאיסורים הקשיחים. ההנחיה בקוד, בקבוע `prompt` במודול V95.
- הקריאה נעשית דרך יכולת `sample` של claude.ai בדף עצמו, במכסה של המשתמש הצופה. מחוץ ל-claude.ai הכפתור מסביר שהוא לא זמין.
- אחרי התשובה: ניקוי אוטומטי (מקפים, סימני קריאה, סוגריים), בדיקת אורך כותרת ושורת משנה, שמירת קישור הכתבה, הוספת החתימה וההאשטגים. בעיות שנשארו מוצגות בשורת "לבדיקה".
- לפני ההחלפה נשמרת גרסה בהיסטוריית הגרסאות, ומופיע כפתור "ביטול" ל-7 שניות.
- אפשר לתת הנחיה חופשית ולבחור את סוג הסיום (שאלה, בחירה, מילה בתגובה, שמרו, שלחו, תייגו, טלפון, קישור לכתבה, עמדה).
