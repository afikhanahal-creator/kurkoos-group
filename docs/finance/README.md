# מערכת הנהלת החשבונות של קבוצת קורקוס

מערכת פנימית לאיסוף חשבוניות וקבלות, בסגנון Wellybox, במיתוג של הקבוצה.
כתובת: `/admin/finance` (אותה כניסה של האדמין). קישור גם מתפריט האדמין: מערכת › הנהלת חשבונות.

## הפעלה (פעם אחת)

1. **מסד הנתונים**: Supabase › SQL Editor › להריץ את `supabase/finance.sql` (בטוח להרצה חוזרת).
2. **Google Cloud Console** (בחשבון Google של המשרד):
   - פרויקט חדש › APIs & Services › להפעיל את **Gmail API**.
   - OAuth consent screen: אם התיבות הן Google Workspace של `kurkoos.co.il`, לבחור **Internal**. כך אין צורך באישור של Google, וההרשאה לא פגה.
     תיבת `@gmail.com` פרטית דורשת External: במצב Testing ההרשאה פגה אחרי 7 ימים, ולכן לקבע אותה צריך לעבור אימות של Google (ה-scope ‏gmail.readonly מוגבל).
   - Credentials › Create OAuth client ID › Web application.
     Authorized redirect URI: `https://<הדומיין של האתר>/api/finance-oauth`
3. **Vercel › Settings › Environment Variables**:
   - `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` (מהשלב הקודם)
   - `SUPABASE_SERVICE_ROLE_KEY`, `ANTHROPIC_API_KEY` (כנראה כבר קיימים)
   - `CRON_SECRET`: מחרוזת אקראית ארוכה. Vercel שולח אותה לסריקה היומית
   - לא חובה: `FINANCE_MODEL` (ברירת מחדל `claude-opus-5-5`), `FINANCE_EFFORT` (ברירת מחדל `low`, אפשר `medium` אם יש טעויות), `SITE_URL`
4. Deploy, ואז במערכת: הגדרות › להוסיף את החברות עם הח.פ והמייל של רו״ח › תיבות מייל › חיבור Gmail › סריקה.

## אבטחה

- כל הטבלאות זמינות רק למשתמשי אדמין מחוברים (RLS).
- הטוקנים של Google שמורים בטבלה `fin_mailbox_secrets` שאין לה שום policy: רק השרת קורא אותה, הם לא מגיעים לדפדפן.
- הקבצים בדלי פרטי `finance-docs`. הדפדפן מוריד אותם רק עם הכניסה של האדמין.
- הרשאת Gmail היא קריאה בלבד. ניתוק תיבה מבטל את ההרשאה אצל Google.

## אחסון (חשוב)

התוכנית החינמית של Supabase נותנת 1GB לכל הארגון (ראו CLAUDE.md). חשבונית PDF היא בערך 50 עד 300KB, כלומר כ-200MB לכל 1,000 מסמכים.
הסריקה בודקת את `storage_usage()` לפני כל מסמך ונעצרת ב-75%, עם הודעה במסך התיבות. כשהנפח מתקרב לגבול, צריך לשדרג את Supabase או להעביר את הקבצים לאחסון אחר.

## הגבלות ידועות

- כל קריאה ל-API מוגבלת ל-60 שניות, ולכן סריקה עוצרת אחרי כ-45 שניות וממשיכה בפעם הבאה (במסך: "יש עוד מיילים, לחצו שוב"). סריקה ראשונה של תיבה עמוסה דורשת כמה לחיצות.
- Vercel בתוכנית החינמית מריץ cron פעם ביום.
- חשבוניות שמגיעות רק כקישור ("להורדת החשבונית לחצו כאן") עוד לא נאספות. זה בשלב 2.
