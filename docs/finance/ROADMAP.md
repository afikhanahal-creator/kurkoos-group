## 2. תוכנית מוצעת (בסדר הזה, אלא אם תחליט אחרת)

1. **אבטחת התחברות** (בלי תלות בך): MFA ב-TOTP (Supabase), חובה לפי תפקיד; ניתוק אחרי חוסר פעילות; ניתוק מכל המכשירים;
   רישום כניסות וכשלונות; מסך "ניהול משתמשים" עם הסטטיסטיקות; תפקיד Viewer.
2. **מודול מע״מ**: ארבעת המצבים, סוגי מסמכים (פטור, אפס, חו״ל, מעורב), כללי זכאות לפי קטגוריה, אישור רו״ח, דוח חודשי ורבעוני.
3. **אוטומציה לרו״ח**: חבילה חודשית בתיקיות, מסך אישור, שליחה אוטומטית רק אחרי הפעלה מפורשת של מנהל.
4. **מרכז אינטגרציות**: קטלוג, אשף, ספק מותאם, ייבוא קבצים עם מיפוי. מתאם API אמיתי רק לספק שתבחר ושתיתן לו מפתח.
5. **תת-דומיין** `finance.kurkoos-group.co.il`: אפשר להכין בקוד עכשיו; ההפעלה תלויה בגישה שלך.
6. **סיכומים בשרת** לביצועים מעל 20,000 מסמכים.

## 3. מה אני צריך ממך

- **DNS**: גישה ל-box.co.il, או שתוסיף בעצמך רשומת `CNAME finance → cname.vercel-dns.com`, והוספת הדומיין בפרויקט ב-Vercel.
- **Gmail של העסק**: לאשר את חיבור ה-OAuth פעם אחת (המפתחות של Google כבר נדרשים ב-Vercel: `GOOGLE_CLIENT_ID/SECRET`).
- **Green API**: לוודא שה-webhook של המופע מכוון למערכת, ולבדוק כמה היסטוריה החשבון מאפשר.
- **ספקי הנהלת חשבונות**: באיזו תוכנה רו״ח עובד, ומפתח API ממנה. בלי מפתח אמיתי אציג את הספק כ"לא מחובר".
- **לוגואים**: שימוש בלוגו של חברה בתוך מערכת פנימית מקובל, אבל כל לוגו צריך להגיע מהאתר הרשמי או מ-media kit. אאסוף אותם
  ואסמן את המקור; לוגו שלא אמצא ממקור רשמי יוצג כ-placeholder.
- **עלות**: סריקת 4 שנים של תיבה פעילה יכולה להיות אלפי קבצים, וכל קובץ שנקרא עולה קריאה ל-Claude. אציג הערכה לפני ההרצה.
- **מדיניות**: למי MFA חובה; אחרי כמה דקות חוסר פעילות לנתק; האם להפעיל שליחה חודשית אוטומטית לרו״ח.
