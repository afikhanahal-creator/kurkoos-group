# בדיקת קצה-לקצה · KURKOOS FINANCE AI

הבדיקה מרימה עותק מקומי של Supabase ומריצה את המערכת האמיתית מולו, בדפדפן Chromium (Playwright):
מסד Postgres עם כל ההרשאות והטריגרים, Supabase Auth (GoTrue), Supabase Storage, PostgREST, קוד השרת ללא שינוי, והממשק.

**מה מדומה:** Google OAuth + Gmail API, ‏Claude, ‏Resend ושרת SMTP (scripts/finance-e2e/fakes.mjs). הם מדברים באותו פורמט HTTP של השירותים האמיתיים.
Claude המדומה עונה מטבלה לפי טביעת הקובץ, ולכן הבדיקה בודקת את כל מה שמסביב ל-AI ולא את איכות הקריאה שלו. את זה בודקים עם מפתח אמיתי (למטה).

## הרצה

```bash
scripts/finance-e2e/pg.sh               # Postgres 16 מקומי על 54329
psql -h 127.0.0.1 -p 54329 -U postgres -f scripts/finance-e2e/bootstrap.sql
scripts/finance-e2e/stack.sh            # GoTrue, PostgREST, Storage בדוקר
psql ... -f scripts/finance-e2e/post-auth.sql
psql ... -f supabase/migration.sql -f scripts/storage/storage-usage.sql -f supabase/finance.sql
node scripts/finance-e2e/fixtures.mjs   # חשבוניות PDF ותמונה אמיתיות
scripts/finance-e2e/services.sh         # fakes, gateway + api, vite
node scripts/finance-e2e/run.mjs        # התרחישים, צילומים ו-results.json ב-/var/tmp/fin-shots
```
