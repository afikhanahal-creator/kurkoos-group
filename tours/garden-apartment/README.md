# דירת גן 250 מ"ר: סיור תלת-ממדי

`index.html` הוא קובץ אחד שעומד בפני עצמו: Three.js, המודל והממשק נמצאים בתוכו. פותחים אותו בלחיצה כפולה,
בלי שרת ובלי אינטרנט. אפשר לשלוח אותו לקונים כמו שהוא.

- `src/tour.js`: המודל (קירות, פתחים, רצפות, ריהוט, אור שמש, הליכה והתנגשויות).
- `src/template.html`: הממשק בעברית.
- `src/build.mjs`: מאחד הכול ל-`index.html`.

בנייה מחדש אחרי שינוי: `npm install && npm run build` בתיקייה הזאת.

## הנחות המודל
- צפון בצד החצר האנגלית. x = מזרח, z = דרום, מטרים.
- תקרה 3.80, ו-3.40 מתחת להנמכות הגבס בשתי הקומות. בין רצפה לרצפה 4.10.
- הקירות: חוץ 25 ס"מ, פנים 10 ס"מ, ממ"ד 30 ס"מ.
- הריצוף: פורצלן 120x120 בכל הקומות, בארבעה גוונים לפי סוג החדר.
- הוויטרינות בסלון: הזזה, ברוחב 5.20 ו-2.90 ובגובה 3.40.
- המדרגות: U, 22 רומים של 18.6 ס"מ. בתוכנית מסומן 2.97 בין הקומות. בגובה 4.10 צריך מדרגות בצורת U ולא מהלך ישר אחד.
- הבדיקה: `window.__tour.measureAll()` מודדת כל חדר עם קרניים מול הקירות ומשווה לתוכנית.
