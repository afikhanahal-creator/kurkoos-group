# דירת גן 250 מ"ר: סיור תלת-ממדי

`index.html` הוא קובץ אחד שעומד בפני עצמו: Three.js, המודל והממשק נמצאים בתוכו. פותחים אותו בלחיצה כפולה,
בלי שרת ובלי אינטרנט. אפשר לשלוח אותו לקונים כמו שהוא.

- `src/tour.js`: הסיור (קירות ופתחים מ-`src/layout.json`, ריהוט, 3 סגנונות, 4 שעות ביום, סיור מודרך, הליכה והתנגשויות).
- `src/layout.json`: התוכנית המתוקנת (קירות, דלתות, חלונות, רצפות), נוצרת מ-`blender/build_apartment.py` כדי שהסיור והרינדורים יהיו על אותה תוכנית.
- `src/assets/`: טקסטורות, תמונות קיר ופנורמות עיר מ-Poly Haven (CC0), מוקטנות לאתר.
- `blender/`: בניית המודל ב-Blender, הורדת הנכסים מ-Poly Haven, עיצוב ותאורה פוטוריאליסטיים ומצלמות צילום.
- `src/template.html`: הממשק בעברית. במחשב פאנל צד, בטלפון סרגל תחתון וגיליון אפשרויות.
- `src/build.mjs`: מאחד הכול ל-`index.html`.

תצוגות: בתוך הדירה (נקודת צילום בכל חדר: גובה עיניים, מצלמה ישרה, עדשה רחבה), דגם מלמעלה לכל קומה, ו"שתי הקומות" זו לצד זו.
גלגלת אחורה או צביטה בתוך הבית יוצאות החוצה לדגם; התרחקות בדגם מראה את הבניין מבחוץ; לחיצה על חדר בדגם נכנסת אליו.
בטלפון: גרירה להסתכל, הקשה על הרצפה כדי ללכת, ג'ויסטיק.

בנייה מחדש אחרי שינוי: `npm install && npm run build` בתיקייה הזאת.

## הנחות המודל
- צפון בצד החצר האנגלית. x = מזרח, z = דרום, מטרים.
- תקרה 3.80, ו-3.40 מתחת להנמכות הגבס בשתי הקומות. בין רצפה לרצפה 4.10.
- הקירות: חוץ 25 ס"מ, פנים 10 ס"מ, ממ"ד 30 ס"מ.
- הריצוף: פורצלן 120x120 בכל הקומות, בארבעה גוונים לפי סוג החדר.
- הוויטרינות בסלון: הזזה, ברוחב 5.20 ו-2.90 ובגובה 3.40.
- המדרגות: U עם 7 מדרגות פנייה, 22 רומים של 18.6 ס"מ. בתוכנית מסומן 2.97 בין הקומות. בגובה 4.10 צריך מדרגות בצורת U ולא מהלך ישר אחד.
- הסיור המודרך: 12 עצירות, כ-82 שניות. `__tour.tourClear()` בודק שהמסלול לא עובר דרך קיר או רהיט.
- הבדיקה: `window.__tour.measureAll()` מודדת כל חדר עם קרניים מול הקירות ומשווה לתוכנית.
